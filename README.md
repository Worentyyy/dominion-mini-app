# DOMINION Mini App

Отдельное Telegram Web App-приложение для:
- Главной
- Battle Pass
- покупки кристаллов за Telegram Stars
- покупки привилегий VIP / Корона / Божественная

## Важно
Это первый отдельный фронтенд-прототип. Покупки сейчас являются визуальной заглушкой:
они показывают уведомление и НЕ списывают реальные Stars.

Для реальных платежей понадобится связать `app.js` с существующим Python/Aiogram-ботом:
1. Web App открывается из Telegram через кнопку `web_app`.
2. Frontend отправляет данные покупки боту/Backend.
3. Backend создаёт Telegram invoice.
4. Telegram проводит оплату Stars.
5. Backend после успешной оплаты начисляет кристаллы/активирует привилегию/Battle Pass.

## Запуск локально

Не открывай `index.html` двойным кликом для финального теста — лучше запусти локальный HTTP-сервер:

```bash
python -m http.server 8080
```

После этого открой:
`http://127.0.0.1:8080`

Для Telegram Mini App нужен публичный HTTPS-адрес. Для разработки можно использовать любой подходящий HTTPS-хостинг/туннель.
