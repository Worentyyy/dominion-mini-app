# DOMINION Mini App — этап 1: профиль

Это самостоятельный слой Mini App поверх существующего бота. Исходный файл бота не заменяется и не редактируется.

## Перед запуском

1. Отзовите токен, который был записан в старом исходном файле, через BotFather. Новый токен не должен попадать в Git или код.
2. Сохраните файл бота с корректным именем, например `dominion.py`, в его обычной серверной папке.
3. Убедитесь, что бот уже запускался с этой папки хотя бы раз: он создаст и мигрирует `dominion.db`.

## Запуск API

Из папки с этим результатом установите зависимости:

```powershell
py -m pip install -r requirements-api.txt
```

Задайте переменные окружения и запустите один процесс API:

```powershell
$env:DOMINION_BOT_TOKEN = "новый-токен-бота"
$env:DOMINION_BOT_SOURCE_DIR = "C:\path\to\bot"
$env:DOMINION_BOT_MODULE = "dominion"
$env:DOMINION_DB_PATH = "C:\path\to\bot\dominion.db"
py -m uvicorn api_server:app --host 127.0.0.1 --port 8080
```

`api_server.py` импортирует функции из существующего `dominion.py`, но не запускает polling: у основного файла срабатывает его обычная проверка `if __name__ == "__main__"`.

Откройте сервер через HTTPS-домен и укажите этот же URL в настройках Telegram Mini App. Когда HTML и API отдаются этим сервером, `dominion-api-base` в `index.html` оставляется пустым — запросы будут same-origin. Если фронтенд размещён отдельно, задайте в метатеге URL API и `DOMINION_MINI_APP_ORIGINS` точным списком HTTPS-origin'ов через запятую.

## API

- `GET /api/me/profile` — только читает профиль авторизованного игрока.
- `POST /api/me/avatar` — принимает только `{"avatar_key":"mage"}` из фиксированного списка и сохраняет ключ в `players.avatar_key`.

Оба endpoint'а требуют заголовок `X-Telegram-Init-Data`. API проверяет подпись HMAC Telegram и срок `auth_date`, затем извлекает ID только из подписанного объекта `user`. Браузер не передаёт ID, баланс, XP или иные игровые показатели.

`POST /api/me/avatar` при первом вызове безопасно добавляет nullable-колонку `avatar_key` через idempotent-миграцию. Это единственное изменение схемы на первом этапе.

## Проверка в Telegram

Обычный браузер без Telegram намеренно покажет ошибку авторизации на экране профиля. Это ожидаемое поведение: демо-значения не подменяют данные из игры.
